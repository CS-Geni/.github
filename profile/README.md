# CS-Geni

A free path into computer science for people starting with no background.

**[Start learning](https://cs-geni.github.io/public/)** · **[Study map](https://github.com/CS-Geni/curriculum)** · **[Labs](https://github.com/CS-Geni/labs)** · **[Capstones](https://github.com/CS-Geni/projects)**

The [learning site](https://cs-geni.github.io/public/) is 12 tracks and 15 courses: plain-language lessons, practice, and a capstone at the end of each course. Progress is saved in your browser. You do not need an account to study.

The [showcase](https://cs-geni.github.io/public/showcase/) is the short version of the idea: change a variable, step a loop, push and pop a stack.

## The path

Start with no jargon. Write small programs. Then data structures, discrete math, and the machine itself. Then operating systems, networks, and databases. Then the professional work: Git, shipping, security, and a careful introduction to data and models. The last course builds a tiny language, which only makes sense after the earlier ones.

## Principles

1. **Start where you are.** The first course assumes a browser, not a degree.
2. **See the idea move.** A variable, a loop, and a stack are things you can change and watch.
3. **Build toward a real skill.** Every course ends in a project with a definition of done.
